# Demo Run Guide

## Prerequisites
- Git 2.23 or later
- JDK 17 or later, with both `java` and `javac` available
- Python 3.9 or later

## Running the Demo
Run the following command from the exercise workspace:

```sh
python3 run.py demo
```

## What the Demo Does
The demo uses a fixed date of September 1, 2026. It displays the borrowing limits for students and faculty, both set to two books, and searches for titles containing `git`.

It then demonstrates Alex borrowing and returning *Git Essentials*. The loan is due on September 15, 2026. After the return, the overdue fee is zero and no active loans remain.
